# CPP Module 01

> Memory allocation, pointers and references.

## What's inside

- Allocation with new / delete
- Pointers vs references
- Pointers to member functions
- switch statement
- Exercises: Zombie, HumanA / HumanB, file replace, Harl

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
